## 7. 复查建议（每次改代码后执行）

1. 先改代码，再更新 `README.md` / `docs/PRD.md` / `docs/流程图.md`。  
2. 逐条复查本清单中 “核心流程一致性” 与 “摘要发布一致性”。  
3. 若新增能力（如自动重试、批量发布、审核流），先更新本清单再改 PRD。  
4. 发布前保证本清单所有项均为 `[x]`。
