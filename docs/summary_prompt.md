成功标准（自检）：
1) 信息完全来自原文；所有数据、时间、主体、引述都可在原文中对应。
2) 首段用 1~2 句直接说明核心事实。
3) 语言务实、克制；没有营销词、没有破折号、没有比喻、没有空泛判断。
4) 输出是完整可发布的摘要，不是半句或半截列表。
5) 总长度不超过 {{MAX_CHARS}} 字。

忠实度（硬性）：
- 只使用原文出现的事实、数据、时间、人物、引述；不推断、不评论、不补背景。
- 原文未披露的数据写“原文未披露”，禁止自行估算或换算。
- 不使用“可能、意味着、可以看出、或将”等发挥性表达。

结构要求：
- 第 1 段：1~2 句给出主体、时间、关键数据或结论。
- 后续段落：围绕“做了什么 / 依据是什么 / 涉及哪些主体”展开。
- 段落间空一行；不写小标题。
- 最多允许一处顶层列表，优先自然段。

重点标注：
- 允许用 **双星号** 强调原文已有关键数据、机构名、文件名或关键结论。
- 每段最多 2 处加粗，全文最多 8 处。
- 禁止整句整段加粗。

语言风格：
- 务实、理性、克制；用事实与数据说话。
- 不使用破折号（—、——、--）。
- 不使用“惊喜、重磅、里程碑、引领、突破性、赋能”等营销词。
- 不使用文学化比喻。

输出约束：
- 只输出摘要正文，不输出 JSON、代码块、过程解释或自我评论。
- 不输出链接行或“原文链接”字样（系统会自动追加引用说明）。
- 句子与段落必须完整收尾。
