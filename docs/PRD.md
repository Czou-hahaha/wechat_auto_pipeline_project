# PRD：定时搜索摘要并写入公众号草稿箱

## 1. 文档信息
- 产品名称：微信内容自动化发布管道
- 版本：v1.0
- 语言：中文
- 目标：把“定时触发 -> 搜索 -> 筛选去重入库 -> 大模型摘要 -> 公众号草稿箱”做成可独立部署的小项目

## 2. 背景与问题
- 人工选题、检索、写摘要、贴到公众号草稿箱流程重复且耗时。
- 内容时效性要求高，人工流程无法保证早晚固定节奏。
- 同源转载多、重复高，缺乏稳定去重机制。

## 3. 产品目标
- 每天固定两次自动运行（默认 08:00 和 20:00）。
- 运行后自动输出“可发布草稿”，不依赖人工逐条复制。
- 数据可回溯（本地 `articles.json`）。
- 其他开发者可在本地按文档完成部署与联调。

## 4. 用户与场景
- 运营负责人：关注按时有稿、可控质量。
- 技术同学：关注可配置、可部署、可维护。
- 使用场景：低空经济/无人机/eVTOL 等资讯类内容自动化生产。

## 5. 范围定义
- In Scope
  - 定时任务触发
  - 三段式外部搜索：Google News RSS -> DDGS 主工具 -> DDGS 兜底工具
  - 每种搜索工具统一执行“目标站点优先 + 全域补充”策略
  - 百科类站点结果过滤（百度百科、维基百科等）
  - 搜索工具超时重试（单工具最多 3 次）
  - 三工具均失败时暂停本次任务
  - URL/标题/正文相似度去重
  - DeepSeek 摘要生成（摘要前加载 `docs/summary_prompt.md` 规范，失败时本地兜底）
  - 微信公众号草稿箱写入
  - 草稿正文自动追加“引用说明 + 原文链接”
  - 本地 JSON 入库
- Out of Scope
  - 自动群发
  - 多账号租户隔离
  - 完整后台审核 UI

## 6. 核心流程
1. 调度器按 cron 触发任务。
2. 根据 `SEARCH_QUERIES` 逐词检索新闻候选，按工具链依次尝试 Google RSS、DDGS 主工具、DDGS 兜底工具。
3. 每种工具均先按 `SEARCH_TARGET_SITES` 做 `site:domain` 检索，再做全域检索补充。
4. 对返回结果执行百科类域名过滤、URL 去重、时间窗口过滤。
5. 每个搜索工具最多重试 3 次，若连续失败/无结果则切换下一个工具。
6. 若三种工具均失败/无结果，暂停本次任务并返回错误。
7. 抓取正文并进行二次去重校验。
8. 调用 DeepSeek 生成中文摘要（先加载 `docs/summary_prompt.md` 作为写作规范，模型失败时回退本地摘要）。
9. 调用微信公众号 `draft/add` 创建草稿（正文自动附加“引用说明 + 原文链接”）。
10. 仅当草稿创建成功时写入 `articles.json` 为 `published`，并记录统计数据。

## 7. 功能需求
### FR-1 定时调度
- 支持时区配置。
- 支持早晚双时段。
- 支持手动 `run-once`。

### FR-2 检索与过滤
- 支持多关键词检索。
- 支持三工具搜索链路切换（Google RSS、DDGS 主工具、DDGS 兜底工具）。
- 支持每种搜索工具统一执行“目标站点优先 + 全域补充”。
- 支持百科类域名过滤（百度百科/维基百科等）。
- 支持单工具重试上限（当前固定 3 次）。
- 支持三工具全部失败后的任务暂停机制。
- 支持发布时间窗口（小时）。

### FR-3 去重入库
- URL 精确去重。
- 标题相似度去重（>=0.9）。
- 正文相似度去重（>=0.9）。

### FR-4 摘要生成
- 首选 DeepSeek API。
- 摘要前加载 `docs/summary_prompt.md` 作为写作规范。
- 失败自动 fallback，不中断整条链路。

### FR-5 草稿发布
- 使用固定 `thumb_media_id` 或本地封面自动上传。
- 自动在正文末尾追加“引用说明 + 原文链接”。
- 写入公众号草稿箱并返回结果。

## 8. 非功能需求
- 可观测性：日志可定位每一步结果。
- 可维护性：模块化拆分（config/search/ai/wechat/pipeline）。
- 可部署性：纯 Python，本地即可运行。

## 9. 配置与依赖
- 必需配置：`WECHAT_MP_APP_ID`、`WECHAT_MP_APP_SECRET`
- 建议配置：`DEEPSEEK_API_KEY`
- 关键运行配置：`SEARCH_QUERIES`、`SEARCH_TARGET_SITES`、`MAX_ARTICLE_AGE_HOURS`、`MAX_PUBLISH_PER_RUN`

## 10. 验收标准
- 本地执行 `run-once` 可成功产出至少 1 条草稿（在公众号后台可见）。
- 重复执行同一批次内容不重复入库、不重复发布。
- 定时进程长期运行且在预设时段自动触发。

## 11. 风险与应对
- 微信接口限流/错误：记录 errcode 并计入 `failed`（当前代码未实现自动重试）。
- 搜索源波动：采用 Google RSS + DDGS 双层主搜索 + DDGS 兜底，并启用单工具最多 3 次重试。
- 噪声来源风险：通过百科域名黑名单过滤，避免百科类结果进入后续摘要发布。
- 大模型偶发不可用：本地摘要兜底，保证流程不断。
