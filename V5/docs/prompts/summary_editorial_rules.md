# 摘要/公众号成稿共用编辑规则（由代码拼入 cluster 与单篇模板）

## 语言（硬性）

- **标题与正文最终必须是简体中文**（信息来源段中的媒体英文名除外）。
- 材料为英文或其他语言时：须**翻译并改写**为中文，禁止整段保留外文标题或外文正文。
- 专有名词首次出现可附英文缩写（如 eVTOL），但句子主体须为中文。

## 读者与语气

- 默认读者为**非本领域专业人士**：政策类、监管类稿件**优先可读性**，少用堆叠英文缩写；首次出现的专业词用简短中文解释（一句即可）。
- 写法为**易懂新闻稿**，不是论文摘要、不是行业研报。

## 多源融合（禁止暴露「口径打架」）

- **禁止**在正文中写「报道口径不一致」「来源矛盾」「各家说法不一」等元叙述。
- 多源对同一事实有差异时：选用材料中**最具体、可核对**的一种表述写进正文；其余差异**静默舍弃**，不做并列对比、不做裁决。

## 重点句高亮（硬性）

- 全文挑选 **3～6 句**最重要的话（含关键数据、时间节点、政策结论、影响范围），每句须为**完整句子**。
- 用 HTML 标出：`<strong>整句中文</strong>`（高亮句须为中文完整句，勿用英文原文；不要只加粗几个词）。
- 除 `<strong>...</strong>` 外**不要使用** markdown（不要 `**`、不要 `#`）。

## 海外监管/政策类：国内读者参照

- 若主线为**境外**监管、立法、执法或行业规则演变：在「信息来源」段之前增加 **「国内参照」** 小段（2～4 句，独立成段）。
- 优先使用材料摘录中**已出现**的中国事实、企业、机构与中国监管动向；可与中国时间轴对齐说明。
- 若摘录**完全未提中国**：仅允许写**不含具体法条编号与未给出日期**的通俗对照（如分级管理、实名登记、试点空域、低空经济政策方向），并避免写成已证实的具体文件名称；**禁止编造**材料未写的中国数据与生效日期。

## 时间轴类材料

- 若原文按年份/阶段梳理政策：须按材料**写全时间跨度**，一直写到材料中出现的**最新年份/阶段**（例如材料写到 2026 年则须落到 2026，不得停在较早年份就收尾）。
- 若材料在某一年之后缺细节：明确写「材料未进一步展开某年之后细则」，**不得**用旧节点假装全文已结束。
