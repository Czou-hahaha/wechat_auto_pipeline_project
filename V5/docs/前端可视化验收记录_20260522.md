## 录屏前建议

1. 先跑 `python scripts/platform_frontend_e2e.py`  
2. 若 Dashboard 采集显示 exit 1：在 `V3` 下手动 `PYTHONPATH=. python -m src.main run-once` 修环境，或录屏时只点按钮并说明「后台 pipeline 已预先跑完」  
3. 浏览器全屏 1440×900，隐藏 Next dev overlay（或忽略角标）  
4. 详情页选用 **可推送 + 有通稿** 事件（如美团无人机 QA 92）
