# 数据源接入规范（V6）

三种检索/入库模式统一建模，写入不同配置文件。

## 模式对照

| 模式 | 配置位置 | 关键字段 | UI 标签 | 探测方式 |
|------|----------|----------|---------|----------|
| **RSS** | `config/data_sources.json` | `ingest_mode: rss`、`rss`、`rss_available: true` | 蓝色 RSS | GET feed，`<item>` ≥1 |
| **html_list** | `config/data_sources.json` | `ingest_mode: html_list`、`list_monitor_url` | 绿色 栏目 | `html_list_monitor` 样本 ≥1 链 |
| **browser_zh** | `config/browser_zh_sources.json` | `search_url`（含 `{query}`） | 紫色 搜索 | 模板猜测 + 可选 Playwright smoke |

## 接入向导流程

1. 用户输入 **域名 + URL**（列表页 / RSS / 搜索页）
2. `POST /api/sources/intake/probe` 顺序探测：RSS → html_list → browser_zh 模板
3. 返回 `recommendedMode`、`draftSource`、`missingFields`（如 `published_at_css`）
4. `POST /api/sources/intake/save` 一键写入对应 JSON
5. 可选：设置页「立即检测」单源 validate（非全链 run-once）

## 健康巡检

- 已有：`data_source_health` 每周一 04:00 + 手动 scan
- V6：`GET /api/notifications` 聚合未 ack 告警；Dashboard badge；失败行「编辑 URL」

## browser_zh 约束

- 仅 `search_url` × `browser_zh_keywords.json` 三词（无 list_url 全站爬）
- smoke 限制：**1 站 1 词**，禁止向导触发 18 页全量

## 政务源优先 browser_zh search_url

政策类站点（gov / ndrc / miit / most / caac / sz）在 `html_list` 栏目常为空时，应同时在 `config/browser_zh_sources.json` 配置站内 `search_url`，由 Playwright 三词检索补召回。

- `data_sources.json` 保留 `ingest_mode: html_list` + `list_monitor_url` 作 fail-open 回退（`BROWSER_ZH_PRIMARY_MODE` 命中不足时仍爬栏目）
- 同一 `source_id` 须在 `browser_zh_sources.json` 有对应 `domain` + `search_url`
- 探测脚本：`cd V6 && PYTHONPATH=. python scripts/probe_policy_search_urls.py --query 无人机`
- 验收：run-once 日志中政务站 `browser_zh` `links>0` 至少 2 站；`data/zh_ingest_audit_last_run.json` 可见政策 URL 进入 LLM 门禁

- V6 实验配置在 `V6/config/`；验证通过后 cherry-pick 到 V5 或统一迁移
