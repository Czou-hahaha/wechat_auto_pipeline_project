## 六、已知缺陷（建议修复优先级）

### P0 — 阻塞上线

1. **历史事件图谱 API 500**  
   - 根因：`event_intelligence_graph/service.py` 读取 `TimelineEntry.kind`，旧快照字段为 `kind` 枚举缺失。  
   - 复现：`GET /api/events/e06842b5-.../graph` → 500；新跑图谱后 `GET .../5f92fcfc-.../graph` → 200。  
   - 建议：兼容旧 timeline 结构或迁移 `event_graph/graph_snapshot.json`。

### P1 — 质量与可观测性

2. **扩搜 GDELT query 未截断至 12 词**（见 §3.6）  
3. **`/api/pipeline/status` 未随 CLI run-once 更新**（仍显示 2026-05-31 旧任务；仅 Dashboard POST 触发会刷新）  
4. **部分历史事件详情 `articles=[]`**，导致 `sourceKind` 冒烟失败（可能与推送后清空正文策略有关）

### P2 — 测试资产

5. 补齐 `tests/data/dedupe_runs/beijing` 或跳过 hydrate 集成测  
6. 更新 `test_gdelt_search_serial` / `test_summary_html` 与当前 `Settings`、`pipeline` 结构对齐  
7. `acceptance_smoke.py` 默认端口应改为 **8788**（或读 `BFF_PORT`）
