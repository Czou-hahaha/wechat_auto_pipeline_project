# V3 上线前文章校验标准

适用范围：`V3` 自动检索（RSS / 栏目页 / GDELT）→ 抓取落地页 → 摘要 → 公众号草稿箱链路。

## 1) 时间窗口硬规则

- **有可靠时刻**的 `source_published_at`：须落在 `MAX_ARTICLE_AGE_HOURS` 窗口内（默认 `14` 小时）。
- **仅日历日**（页面上无具体时分、或解析为「日」精度）：使用 `DATE_ONLY_MAX_CALENDAR_AGE_DAYS`（默认 `3`）按 `SCHEDULE_TIMEZONE`（默认上海）的**日历日**判断是否在窗内，避免误杀「仅显示年月日」的当天稿；仍依赖 URL/标题与库内历史去重。
- `source_published_at` 须从**落地页**解析（meta / `time` / 多段 `application/ld+json` / `__NEXT_DATA__` 等内嵌 JSON / `data_sources.json` 中按域名配置的 `published_at_css` / 标题区局部兜底），**不信任**搜索侧时间。
- 落地页仍提取不到发布时间：丢弃，不入库、不推草稿箱。
- 超出上述时间规则：丢弃。

## 2) 主题范围（允许）

- 低空经济、无人机、eVTOL、通用航空相关的：
  - 政策法规与监管动作
  - 国家战略与部委/地方政府部署
  - 行业发展与产业趋势
  - 重大应用落地与行业级动态

## 3) 主题范围（禁止）

- 娱乐影视、游戏应用、应用商店页面
- 百科词条、纯知识科普、教程入门稿
- 企业官网介绍页、产品目录页、招商页、公司主页壳层
- 个人观点专栏、导刊、合集快讯类低信号内容

## 4) 发布前复核

- 推送到公众号草稿箱前再次执行范围校验。
- 任一条不满足范围或时间规则，直接跳过。

## 5) 无稿策略

- 没有符合规则的新闻时，返回 `0` 篇发布。
- 不允许为了凑数量放宽规则或回退到过期稿件。

## 6) 摘要与通稿体例（与生成侧对齐）

- 单篇摘要写作体例、簇摘要模板、事件通稿 system/user 均维护在 **`V3/docs/prompts/`**（见该目录 `README.md`）。
- `SummaryService` 与 `prompt_builder` 运行时从上述 Markdown 加载；迭代语气或禁令时**改 md 即可**，发布前 QA 仍引用同一套 `news_single_summary` 规则（经 `review_summary_for_publish` 注入）。

## 7) 人工核查建议（上线前）

1. 执行：`python -m src.main run-once`
2. 检查日志：
   - `published`
   - `skipped_policy`
   - `skip missing page published_at`
3. 若 `published=0`，视为“本窗口无合格稿件”，属于正常结果。
4. 仅在确认有合格稿件时再执行推送动作。
